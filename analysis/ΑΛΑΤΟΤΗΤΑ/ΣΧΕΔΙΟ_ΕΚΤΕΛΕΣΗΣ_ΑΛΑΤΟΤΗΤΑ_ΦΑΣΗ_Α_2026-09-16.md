### ΒΗΜΑ 4 · Α3 — Πυρήνας v50.136: η προ-αρδευτική αναφορά, σύγχρονη

**Τι:** ανά βάθος, το ζεύγος (θ, σ_w) **του ίδιου δείγματος** στο tick ελάχιστης θ του παραθύρου ημερήσιο→ημερήσιο tick (00:20→00:20 UTC, #219). Εκπομπή `soil_ec_ref1/2` **μία φορά/ημέρα**, σειρά.

**Σχεδιασμός (≈ 30 γραμμές, δύο σημεία):**

*(α) Ωριαία ενημέρωση — αμέσως μετά την κλήση `_sagEcIndicators(...)` (γρ. 18775), όπου υπάρχουν τα `soil_ec_pore1/2` του τρέχοντος tick:*

const _erPrev = _ecRefReset ? {} : _parseJson(_prevShared.ec_ref_state) || {};
const _erNow = {};
for (const c of [{n:1, m:'soil_moisture1', t:'soil_temperature1'}, {n:2, m:'soil_moisture2', t:'soil_temperature2'}]) {
  const sw = _num(_indicatorValue('soil_ec_pore' + c.n)), th = _num(getVal(measurements, c.m)), tt = _num(getVal(measurements, c.t));

### ΒΗΜΑ 5 · Α4 — Πυρήνας v50.137: R, CF, φρουρός, τάση

**Πού:** ημερήσιο μπλοκ, αμέσως μετά την εκπομπή του Α3.

```js
// T-ECRATIO-01 (v50.137): λιπαντήριο — R ως προς το λίπασμα, CF ως προς το νερό (#216, #218)
const _refF = Math.max(ref1 ?? -Infinity, ref2 ?? -Infinity);          // χειρότερο βάθος
const _fert = _numIn(parameters?.fert_ecw_dsm, 0.05, 15);              // ίδιοι φραγμοί με το ecw (7936)
const _ecw  = _numIn(parameters?.water_ecw_dsm, 0.05, 15);
const _lo = Math.min(_fert ?? Infinity, _ecw ?? Infinity), _hi = Math.max(_fert ?? -Infinity, _ecw ?? -Infinity);
if (Number.isFinite(_refF) && Number.isFinite(_lo) && (_refF < 0.7 * _lo || _refF > 2.0 * _hi)) {
  push('soil_ec_ratio', null, { text: 'Ελέγξτε τις δηλώσεις EC νερού/λιπάσματος: το νερό των πόρων (' + _refF + ') είναι έξω από το φυσικά δυνατό εύρος.' , color: 'orange' });
} else {
  if (Number.isFinite(_fert)) push('soil_ec_ratio', round2(_refF / _fert), { unit: '—', zone: _zoneR(_refF / _fert) });
  if (Number.isFinite(_ecw))  push('soil_ec_conc',  round2(_refF / _ecw),  { unit: '—' });
}
// τάση 7ημ: δακτύλιος ec_ref_hist (internal), μέσος 3 τελευταίων ημερών έναντι 3 προηγούμενων
```
Ζώνες `_zoneR` **(ΠΡΟΣΩΡΙΝΕΣ — ζητούν ΟΚ):** `< 0,7` «ξεπλένονται θρεπτικά» · `0,7–1,5` «στόχος» · `1,5–2` «παρακολούθηση» · `> 2` «συσσώρευση». Σιωπή (**κανένα κλειδί**) όταν λείπει η δήλωση. `soil_ec_ratio`, `soil_ec_conc` στο `_SAG_SERIES_KEYS`.

**Ερώτημα σχεδιασμού που θέλει το ΟΚ σου:** το `_refF` = **μέγιστο** των δύο βαθών (χειρότερη περίπτωση) — ή το ρηχό (ριζόστρωμα της ντομάτας); Προτείνω **μέγιστο**, με τη ζώνη να αναφέρει ποιο βάθος.

**Διαφορικός:** λίτρα = 0· **Γρινιαράκης:** R ≈ 0,8, CF ≈ 0,8 (με `water_ecw_dsm` = 3 ακόμη) — και **ο φρουρός δεν** ενεργοποιείται (2,40 ≥ 0,7·3,0 = 2,1). Αγροί χωρίς δήλωση: σιωπή.
