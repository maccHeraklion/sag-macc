# Τοπική αναπαραγωγή του widget

Τρέχει τον ΠΡΑΓΜΑΤΙΚΟ κώδικα του `_dist-sagMain` σε browser, με ψεύτικο `window.TagoIO`. Χρησιμοποίησέ τη όταν ένας ελεγκτής
περνά αλλά το ταμπλό δείχνει άλλο: στις 3/11 ο `widget_substrate_ec_check` έθετε τη σημαία με το χέρι και δεν έπιασε το σφάλμα.

1. Φτιάξε φάκελο εκτός repo με τα αρχεία του `_dist-sagMain` (js, css), και μέσα του έναν υποφάκελο με αυτά τα αρχεία.
2. `node mkfix.js` γράφει το `fixture.js`: ρύθμιση ως μεταβλητή, `field_bundle` συμπιεσμένο, σειρές αισθητήρα.
3. Στο `index.html` φόρτωσε με αυτή τη σειρά: `fixture.js`, `mock.js`, μετά το `index-7cbd9a4e.js` ως module.
4. Σέρβιρε με `python -m http.server` και άνοιξε τη σελίδα. Τα `.meas-card` δείχνουν ό,τι ο πελάτης.

Το `mock.js` κρατά τις μεθόδους με accessors, γιατί το vendor bundle κάνει `window.TagoIO={}` και τις ξαναγράφει.
